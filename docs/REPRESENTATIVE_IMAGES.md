# 150품목 앞면 대표 이미지 인계

AI-server #3의 참고 이미지 자산 목록이다. 추론 코드·모델·입력 전처리를 변경하지 않는다. 이미지 원본은 공개 Git에 포함하지 않는다.

`provenance/representative-front-150.json`은 Backend `supported-drugs.json`의 classId/productCode/itemSeq와 대응한다. 파일·픽셀 해시, 해상도, 원본 상대경로와 원본 라벨 아카이브/멤버를 기록한다. 품목의 법적·의학적 동일성을 육안으로 판정한 자료가 아니라, 데이터셋의 품목·앞면 라벨과 연결된 참고 자료다. 화면에서는 **데이터셋 대표 이미지**로 표기하며 식약처 등록 이미지나 정답 확인 자료로 표현하지 않는다.

## 원본과 재검증

연구 서버 프로젝트의 `artifacts/bundles/pillguide_150_front_back_originals_20261114.zip`에서 앞면만 사용한다. 묶음은 300장(앞/뒤 각 150장)이며 이번 인계 대상은 앞면 150장이다. ZIP SHA-256은 manifest에 고정했다. 원본 바이트·색상·배경·방향을 변경하지 않았다.

```powershell
python scripts/validate_representative_images.py --supported <Backend의-supported-drugs.json> --assets <비공개-앞면-폴더>
```

이미지 루트에는 `000_K-000250/front.png` 같은 150개의 상대경로가 있어야 한다. `--assets`가 없으면 목록 구조·품목 매핑만 검사하며 실제 파일 검증 완료를 뜻하지 않는다. Backend 파일의 원시 바이트 해시는 최초 대조 시점을 기록한 것이며, 이후 줄바꿈 변경 때문에 같은 매핑을 거부하지 않는다. 실제 연결은 정확한 150개 식별자로 검증한다.

## 2026-11-14 검증

- Backend develop `eca9c551eb3f84c86cd9d819a719787b8ef31926`의 지원150품목과 현재 모델 매핑 해시 대조.
- ZIP 전체 해시, 앞면150개 파일·픽셀 해시, PNG 디코딩·해상도, 품목 식별자 일대일 및 중복 없음 확인.
- 연구 서버 기존 선정 기록은 300장의 원본 라벨 대조와 시각 검토를 기록하고 있다. 이번 인계에서도 앞면150개의 확대 미리보기 5장을 에이전트가 재검토했다. 사람이 검수한 결과로 표현하지 않는다.
- 일부 원본의 조명/색편차와 옅은 캡슐 각인은 유지했다. 대표 이미지와 사용자의 사진이 다르게 보일 수 있으며 재촬영·저장 제외 선택을 제공한다.
